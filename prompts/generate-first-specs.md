Using the current project as evidence, generate first-pass behavior specs for
the highest-priority areas.

Use this bootstrap repository as the reference:

https://github.com/potapenko/spec-first-bootstrap

Each spec should include:

- Goal
- Scope
- Non-goals
- User-visible behavior
- Invariants
- Edge cases and failure policy
- Route / state / data implications
- Verification mapping
- Unknowns requiring confirmation

Keep the specs short, explicit, and behavior-level.

Do not turn them into technical design docs.
